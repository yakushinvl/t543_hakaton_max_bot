# Мини-приложение «Афиша и События» для мессенджера MAX (max.ru)

Полнофункциональное мини-приложение для мессенджера **MAX (max.ru)**, помогающее жителям и гостям городов находить интересные мероприятия, получать персональные рекомендации через интерактивный «Флюгер», исследовать события на живой карте, создавать свои встречи и общаться в чатах.

## 🚀 Ключевые возможности

### 1. Интерактивный онбординг с рекомендательным алгоритмом
- **Презентация приложения**: интерактивный тур по ключевым фичам (Флюгер, Карта, Социалка).
- **Подстановка и исправление имени**: автоматическое чтение имени из профиля MAX (`window.WebApp.initDataUnsafe.user`) с возможностью редактирования.
- **Точные возрастные диапазоны**: `6-11`, `12-15`, `16-21`, `22-29`, `30-44`, `45-59`, `60+`.
- **Адаптивный выбор пола**:
  - `6-11` и `12-15` $\rightarrow$ «Мальчик» / «Девочка»
  - `16-21` и `22-29` $\rightarrow$ «Парень» / «Девушка»
  - `30-44`, `45-59`, `60+` $\rightarrow$ «Мужчина» / «Женщина»
- **Apple Watch Home Screen Bubble Grid**: выбор интересов в виде гексагональной сотовой сетки кружочков с тактильным виброоткликом (Haptic Feedback) и плавной анимацией.
- **Генерация алгоритма рекомендаций**: персональный скоринг мероприятий города по интересам, возрасту и времени.

### 2. Разделы приложения (Нижний таббар MAX)
- 🧭 **Флюгер**:
  - Интеллектуальный рекомендательный подбор мероприятий с расчетом процента совпадения (до 99%).
  - Быстрые фильтры: «⭐ Персонально», «🔥 Сегодня», «🎉 Выходные», «🎲 Случайное».
  - Интерактивный спиннер («Крутить флюгер») и карточки с объяснением причин рекомендации.
- 📅 **События (Каталог и «Мои мероприятия»)**:
  - Живой поиск по мероприятиям, артистам и площадкам.
  - Фильтры по датам («Все», «Сегодня», «Завтра», «На выходных») и 15 категориям.
  - Вкладка **«Мои мероприятия»**: «Сохранённые» (избранное), «Хочу пойти», «История».
  - Модальное окно детализации с фото, картой, кнопкой регистрации и переходом в чат.
- 🗺️ **Карта**:
  - Быстрая векторная карта MapLibre GL с кружками-фотографиями мероприятий.
  - Кластеризация `supercluster` со счётчиками-цифрами и цветовой дифференциацией.
  - Bottom sheet карточка быстрого просмотра при нажатии на метку.
  - Переключение городов и геолокация.
- 👥 **Социалка**:
  - Создание своих встреч (публичные и частные по инвайт-ссылке).
  - Приглашение друзей через MAX Bridge (`openLink` / генерация `startapp` ссылки).
  - Встроенный интерактивный чат по каждому мероприятию.
- 👤 **Профиль**:
  - Редактирование имени, возраста, пола и интересов (в сетке Apple Watch).
  - Настройка полей формы регистрации: ФИО, дата рождения, телефон, email (с автозаполнением при записи на события).
  - Статистика посещений и запланированных встреч.

## ⚡ Оптимизация и кэширование (Устранение задержек)
- **Node.js/Express Backend** (`server/`):
  - In-memory кэширование KudaGo API на 45 минут: повторные запросы отдаются за **5–15 мс** вместо 3–5 секунд.
  - Автоматический fallback на генератор городских событий при сбое или таймауте внешнего API.
  - Проксирование картинок `/kg-media/*` с отдачей заголовков `Cache-Control: public, max-age=604800` и CORS-заголовков для чистого рендеринга на Canvas.
- **Client-Side Cache**:
  - Stale-while-revalidate кэширование в LocalStorage: приложение открывается мгновенно, показывая сохраненные данные, пока идет фоновое обновление.

## 🛠️ Запуск и Развёртывание

### Разработка (Frontend + Backend)
```bash
npm run dev
```
- Frontend (Vite): `http://localhost:5173`
- Backend (Express): `http://localhost:3001` (запросы `/api` проксируются)

### Production-сборка
```bash
npm run build
```

### Запуск в продакшене (на `vane.yakuhost.ru`)
```bash
npm start
```
Сервер раздает статическую сборку `dist/` и обрабатывает REST API на порту `PORT` (по умолчанию 3001 или 80/443 через nginx/reverse proxy).
